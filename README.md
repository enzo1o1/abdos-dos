# Abdos & Dos

Programme de 7 séances de 30 minutes à la maison pour la sangle abdominale et le dos : chrono 40 s / 20 s, une page par jour, images de chaque exercice.

Adresse : https://enzo1o1.github.io/abdos-dos/

## Installer sur iPhone
1. Ouvrir l'adresse dans Safari.
2. Toucher le bouton Partager, puis « Sur l'écran d'accueil ».

Après une première ouverture avec Internet, l'application fonctionne aussi sans connexion. Elle se met à jour toute seule à la prochaine ouverture connectée.
